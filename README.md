# Nexus AI - Voice Assistant Package

This directory contains the core logic for the Nexus Voice Assistant.

## 📁 Structure
- `main.py`: Entry point for the assistant.
- `brain/`: Intent classification and training logic.
- `voice/`: Audio listening and speech synthesis.
- `executor/`: Action handlers (opening apps, web search).
- `memory/`: Storage and database management.
- `config.py`: Centralized configuration for apps and settings.

## 🏃 How to Run
For full installation and usage instructions, please refer to the [Root README](../README.md).

Quick Command:
```bash
    python main.py
```
